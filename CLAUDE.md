## How to talk to me in this project

I'm still learning to code, so write every summary for a beginner.

- Keep it brief.
- Use plain English and avoid jargon. If a technical term is unavoidable, explain it in a few words right where it appears.
- Summarise the work as a bullet list with one line per file changed, saying what changed in that file and why, in plain words.
- No code snippets unless I ask for them.
- End with a single "How to check it" line telling me exactly what to look at in the browser to confirm it worked.
